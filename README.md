# userscripts

油猴脚本集合，按网站 / 游戏分目录存放，可用 Tampermonkey 或 Violentmonkey 安装。

A Tampermonkey / Violentmonkey userscript collection, grouped by site or game.

## 脚本 / Scripts

### 银河奶牛放置（Milky Way Idle）

| 脚本 | 说明 |
| --- | --- |
| [空闲自动三采](scripts/mw-idle-auto-gather.user.js) | 无所事事时自动执行自选三采（挤奶 / 采集 / 伐木）和目标。界面支持简体、繁体、English。 |

| Script | Description |
| --- | --- |
| [Idle Triple Gather](scripts/mw-idle-auto-gather.user.js) | When idle, auto-start a chosen gathering action (Milking / Foraging / Woodcutting) and target. UI: English, Simplified Chinese, Traditional Chinese. |

后续其他网站或游戏的脚本会继续加到这里。

## 安装 / Install

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)
2. 打开对应脚本的 Raw 地址，例如：
   - [mw-idle-auto-gather.user.js](https://raw.githubusercontent.com/Jireh012/userscripts/main/scripts/mw-idle-auto-gather.user.js)
3. 浏览器会提示安装；以后更新同一地址即可

也可以把 `scripts/` 里的 `.user.js` 直接拖进扩展。
