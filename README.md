# mwi-userscripts

油猴脚本集合，目前包含银河奶牛放置（Milky Way Idle）相关脚本。

## 脚本

| 脚本 | 说明 |
| --- | --- |
| [MW Idle 空闲自动采集](scripts/mw-idle-auto-gather.user.js) | 无所事事时自动执行自选动作（挤奶 / 采集 / 伐木）和目标（如奥秘树） |

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 打开脚本的 Raw 地址：
   - [mw-idle-auto-gather.user.js](https://raw.githubusercontent.com/Jireh012/mwi-userscripts/main/scripts/mw-idle-auto-gather.user.js)
3. 浏览器会提示安装；以后更新同一地址即可

也可以把 `scripts/` 目录里的 `.user.js` 文件直接拖进 Tampermonkey。

## MW Idle 空闲自动采集

- 适用站点：`milkywayidle.com` / `milkywayidlecn.com`
- 当前版本：`2.4.0`
- 建议勾选「启用」和「后台保活」，并在游戏页点击一次，离开标签页后也能在空闲时自动开始
